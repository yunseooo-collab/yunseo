클립보드에 주소가 복사되었습니다!

과제 제출 가이드 안내

📌 배점 기준 (총 10점)

  • GitHub 내 폴더 생성 (9점): 저장소 내 mylink-folder 작성
  • 마이링크 주소 생성 (1점): 접속 가능한 URL 생성 및 공유

📋 제출 양식 예시:

1. GitHub 저장소 URL:
https://github.com/username/mylink-folder

2. 마이링크(MyLink) URL:
https://username.github.io/mylink-folder/

💡 GitHub Pages 배포 가이드 (3분 완료):

  1. GitHub에 mylink-folder 저장소를 만듭니다.
  2. 이 파일(index.html)을 해당 저장소 루트에 올립니다.
  3. Settings > Pages 메뉴 진입
  4. Source를 Deploy from a branch (main/master)로 지정 후 Save 클릭
